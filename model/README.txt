Jak spustit projekt:

1. Rozbal ZIP.
2. Otevři složku v editoru, třeba VS Code nebo PyCharm.
3. Spusť soubor main.py.

Příkaz v terminálu:
python main.py

Soubory:
- main.py = spuštění programu
- models.py = Uzivatel, Hrac
- figurka.py = základní třída Figurka
- figurky.py = Pesak, Kral
- tah.py = třída Tah
- herni_plocha.py = šachovnice
- revizor_tahu.py = kontrola tahu
- game_logger.py = historie tahů
- game_manager.py = řízení hry
